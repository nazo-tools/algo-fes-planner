# ROUND

algoフェス2026（2026/9/12土・9/13日）を、どの回に出るか決めながら回るための計画ツール。

**https://nazo-tools.github.io/algo-fes-planner/**

## これは何

12公演を1日で全部は回れない。出たい回を自分で押さえて、残った空き時間に入るものを埋める、という順番で組むためのもの。

- **押さえる** — 出たい公演の、出たい回を自分で選ぶ
- **埋める** — 空いたところに入る公演を出す。待ち時間が短くなるように詰める
- ごはんや移動で空けておきたい時間も、先に置いておける
- ★を付けた公演が入らなくなったら、どれを動かせば入るかを出す
- 立てた予定はブラウザに保存される。次に開いたときも残っている

## 非公式です

早稲田大学謎解き企画algo および ESCAPE.ID とは関係のない、個人が作ったファンツールです。

時間割は公式のタイムテーブルから書き写したもので、間違いが残っているかもしれません。
**満席かどうかは反映されません。** 予約と最新の情報は
[escape.id の公式ページ](https://escape.id/fes/algo-fes-2026/) で確かめてください。

公式から取り下げの求めがあれば、すぐに公開をやめます。

## 動かし方

外部への通信はゼロで、1枚のHTMLとして完結している。`docs/index.html` を開けばそのまま動く。

```
npm install
npm test        # ロジックのテスト
node build.mjs  # docs/index.html を作り直す
```

中身は素のJavaScript（ESモジュール）で、フレームワークもビルドツールも使っていない。
`build.mjs` が `shows.js` / `planner.js` / `storage.js` / `ui.js` を `index.html` に埋め込んで、配る用の1枚を吐く。

| ファイル | 中身 |
| --- | --- |
| `shows.js` | 公演と時間割のデータ |
| `planner.js` | 組み合わせの計算（DOMに触らない） |
| `storage.js` | 予定の保存と読み戻し |
| `ui.js` | 画面 |
